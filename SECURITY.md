# Security Policy

Dead Jim is early-stage software, but security and supply-chain issues are welcome reports.

## Reporting a vulnerability

Please avoid publishing exploitable vulnerability details in a public issue before a fix or mitigation can be discussed.

If GitHub private vulnerability reporting is available for this repository, use the repository's **Security** tab to submit a private report. If private reporting is unavailable, open a minimal public issue stating that you have a security report and request a private contact channel without including exploit details.

## Scope

Useful reports include:

- dependency or supply-chain vulnerabilities;
- unsafe parsing of untrusted animation/project data;
- path traversal or arbitrary file access;
- code execution or injection;
- denial-of-service issues caused by malformed source files.

Normal correctness bugs that do not create a security impact should use the regular issue tracker.
